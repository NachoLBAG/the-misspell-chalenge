El desafío del error ortográfico
Aprender en público significa colaborar, y no necesitas ser un experto para contribuir. ¡Los errores ortográficos vienen al rescate! Son el rompehielos perfecto para las contribuciones a proyectos de código abierto, ya que corregirlos es fácil y no requiere mucha experiencia en GitHub o Git.

🔷 Cómo corregir un error ortográfico en una lección de 4Geeks:

1️⃣ Editar en GitHub

Haz clic en el ícono del lápiz que dice "Editar en GitHub" en la parte superior derecha de la lección.
Esto abrirá el archivo fuente de la lección para su edición.
2️⃣ Realizar la corrección

Encuentra y corrige el error ortográfico en el contenido de la lección.
3️⃣ Enviar un Pull Request

Haz clic en "Commit changes" y luego en "Create Pull Request" (Proponer cambio de archivo).
Describe brevemente la corrección realizada y envía tu solicitud.
